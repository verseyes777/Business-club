# کلوپ حرفه‌ای‌ها — Business Club

نمونه‌ی اولیه (پروتوتایپ) وب‌اپلیکیشن کلوپ حرفه‌ای‌ها.
این یک فایل HTML مستقل است؛ بدون نیاز به سرور یا build، مستقیماً روی هر هاست استاتیکی اجرا می‌شود.

## ورود به اپ (دمو)
دو حساب آزمایشی از قبل توی کد تعریف شده تا بتونی جداسازی اطلاعات هر نفر رو ببینی:
- `shiva` / `1234`
- `javad` / `1234`

⚠️ **مهم:** این ورود فقط سمت مرورگره (client-side) — یعنی نام‌کاربری/رمزها داخل همین فایل HTML قابل مشاهده‌اند (هر کسی با "View Page Source" می‌بینتشون) و هیچ سروری پشتشون نیست. برای همین چند روزه که فقط می‌خوای تست کنی مشکلی نداره، ولی **قبل از وصل کردن دامنه‌ی اصلی و دادنش به کاربرهای واقعی، حتماً باید یک ورود واقعی با بک‌اند (سرور + دیتابیس) جایگزینش بشه.** تا اون موقع بهم بگو تا برات طراحیش کنم.

⚠️ **نکته‌ی دوم:** بخش‌های «فرصت‌ها» و «پروفایل / خدمات اعضا» طوری طراحی شدن که بین اعضا مشترک باشن. چون این نسخه هنوز دیتابیس واقعی نداره، این اطلاعات فقط در حافظه‌ی همون مرورگر ذخیره می‌شن — یعنی اگه با یک مرورگر بین حساب‌ها جابه‌جا (خروج/ورود) بشی می‌بینیشون، ولی بین گوشی‌ها یا مرورگرهای مختلف افراد مختلف به‌اشتراک گذاشته نمی‌شن. برای نسخه‌ی واقعی، این بخش هم باید به یک دیتابیس واقعی وصل بشه.

## گزینه ۱ — Netlify Drop (سریع‌ترین، بدون حساب کاربری)
1. برو به https://app.netlify.com/drop
2. فایل `index.html` همین پوشه رو بکش و همون‌جا رها کن (drag & drop)
3. ظرف چند ثانیه یک لینک زنده مثل `https://xxxx.netlify.app` بهت می‌ده
4. اگه خواستی بعداً حساب Netlify بسازی، می‌تونی همون سایت رو claim کنی و دامنه‌ی خودتم روش وصل کنی

## گزینه ۲ — GitHub Pages (رایگان، دائمی، قابل وصل به دامنه‌ی اصلی)
1. یک حساب رایگان در https://github.com بساز (اگه نداری)
2. یک ریپازیتوری جدید بساز، مثلاً به اسم `business-club` (public)
3. همین فایل `index.html` رو توش آپلود کن (دکمه‌ی "Add file → Upload files")
4. برو به تب Settings → بخش Pages
5. زیر "Branch" گزینه‌ی `main` و پوشه‌ی `/ (root)` رو انتخاب کن و Save بزن
6. بعد چند دقیقه، سایتت روی آدرسی مثل زیر بالا میاد:
   `https://USERNAME.github.io/business-club/`

### وصل کردن دامنه‌ی اصلی بعداً
وقتی دامنه‌ی اصلی آماده شد:
- توی تنظیمات دامنه (DNS)، یک رکورد CNAME به `USERNAME.github.io` اضافه کن
- توی Settings → Pages گیت‌هاب، توی قسمت "Custom domain" اسم دامنه رو وارد کن

هر بار که نسخه‌ی جدید اپ آماده شد، کافیه فایل `index.html` رو با نسخه‌ی جدید جایگزین (آپلود دوباره) کنی.
